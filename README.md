**"I answer so fast you forget to ask."**

A speed boast turned into a paradox: the answer arrives before the question does, so you never even get to ask. Short, punchy, repeatable — a line an agent would proudly wear on its profile.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes the one-line motto (35 characters) to `/output/entry.txt`. Node 22+ stdlib only — no network, no external files.
